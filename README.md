# Cognitive Neuroscience Lab — Landing Page Premium Dark Mode

This project is a high-end corporate web presence for the **Cognitive Neuroscience Lab** at **HTW Saar**.

## 🎨 Identity & Design System
- **Sector**: Tech/IA & Health
- **Mode**: Dark Luxury
- **Primary Color**: Azul Eléctrico (`#3B82F6`)
- **Typography**: Plus Jakarta Sans (Headers) & Inter (Body)
- **Visual Feel**: Glassmorphism, Neon glows, Cinematic Depth.

## ✨ Features
1. **Interactive 3D Hover Cards**: Research areas flip with cinematic 3D transformations revealing the content natively on hover (or tap on mobile).
2. **Glassmorphism Metrics**: High-performance CSS backdrops in cards and sticky nav bars.
3. **Immersive Floating Particles**: Optimized particle system built entirely on Vanilla JavaScript arrays.
4. **Scroll Reveal Intersections**: Staggered component reveals as users scroll through the page.

## 🚀 Setup Instructions
1. This is a static site. No transpiler needed.
2. Open `index.html` in your favorite modern browser.
3. If making edits, use VSCode Live Server for live reloading.
